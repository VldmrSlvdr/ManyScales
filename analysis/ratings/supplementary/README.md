# Supplementary rating analyses

`R/` contains fitting and comparison scripts; `stan/` contains the models. Saved summaries are supplied separately through the [OSF project](https://osf.io/hn4fr/) and attached locally under `results/`.

[report.qmd](report.qmd) renders those summaries without refitting. Read the existing [HTML report](../../../reports/supplementary.html). Effects follow the supplied **LLM minus human** convention; HDI/CrI, Bayes factors, and ROPE definitions are retained.

Run fitting scripts from `analysis/ratings/`; task arguments are documented in each source. See the [replication guide](../../../docs/reproduce.md) and [credits](../../../CONTRIBUTORS.md).
