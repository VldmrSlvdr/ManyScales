# Analyses

- `ratings/primary/`: H1 expert ratings, H2 psychometrics, H3 citizen ratings, and related exploratory analyses.
- `ratings/supplementary/`: additional models and sensitivity checks.
- `h4/`: embedding similarity and exploratory relationships with ratings and problem checks.

Data and saved numerical results are supplied separately through the [OSF project](https://osf.io/hn4fr/); the data upload is pending. Follow the [replication guide](../docs/reproduce.md) to attach local inputs. Read the existing [reports](../reports/README.md) without downloading data.
